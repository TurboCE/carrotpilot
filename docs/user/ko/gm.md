# GM 수동 오토홀드

트래버스(SDGM 하네스), 트레일블레이저(일반 ACC), 트랙스의 카메라 종방향 제어에서 지원합니다. 장치의 `AlphaLongitudinalEnabled`를 켜야 하며, CC 전용 모델·가스 인터셉터 구성에서는 작동하지 않습니다. 별도의 오토홀드 토글은 없습니다.

오픈파일럿과 순정 크루즈가 모두 해제된 상태에서 D/L단으로 저속 주행하다 브레이크를 강하게 밟고 완전히 정차하면 유지합니다. 강한 입력 기준은 원시 페달 값 80 이상이며 80%를 뜻하지 않습니다. 1.5 m/s 이하에서 준비할 수 있지만, 실제 유지 명령은 정차 상태에서만 보냅니다. 처음 발을 떼면 유지하고, 이후 가벼운 브레이크 재입력 후 발을 떼면 취소합니다.

가속, 인게이지, 주차 브레이크, D/L 이외 변속, 움직임, CAN 오류·오래된 입력은 유지를 해제합니다. 트레일블레이저는 순정 카메라 명령도 최신이어야 합니다. 유지 중 자동 SET/RES 버튼을 보내지 않습니다.

이 기능을 지원하는 Panda 안전 펌웨어가 필요합니다. 브랜치 반영은 차량 설치나 실차 제동 성능 검증을 의미하지 않습니다. 경사로에서 필요한 제동력을 보장하는 기능으로 검증되지 않았습니다.
